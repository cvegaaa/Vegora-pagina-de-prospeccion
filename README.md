# Vegora — Diagnóstico de Madurez Digital

Herramienta interactiva de diagnóstico usada por Vegora para calificar el nivel de madurez digital de clientes potenciales durante la prospección comercial.

## Qué resuelve

El prospecto responde un cuestionario guiado y obtiene una evaluación de su madurez digital, generando un lead calificado para el equipo comercial de Vegora.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (almacenamiento de resultados/leads)
